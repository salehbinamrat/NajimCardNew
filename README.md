# تريم كارد | Tarim Card

تطبيق Windows مستقل لإدارة وطباعة كروت MikroTik، يُعاد تطويره من الصفر بلغة **C# / .NET 10 / WPF**.

## نطاق المطابقة المعتمد

المطلوب **تطابق جميع صفحات حضرموت ووظائفه وسلوك العمليات والتقارير والطباعة وإدارة MikroTik**؛ وليس مجرد واجهة مشابهة.

- هوية بصرية: الأزرق الكهربائي والفضي مع أيقونات متجهية متعددة الألوان، إطارات هندسية، ورسوم بيانية لبيانات الشبكة الفعلية.
- فصل كامل عن `salehbinzain83-star/Hadramout-cards`، وعن قاعدة بياناته وملفات تشغيله وتراخيصه.
- لا تُستعمل ملفات Python أو أطر تشغيله داخل التطبيق النهائي.
- جميع التغييرات تمر عبر PR واختبارات أولاً؛ يتزامن Windows Core وWindows Release على نفس SHA. يُبنى x86/x64 Portable وInstaller بعد الاختبارات ويُمنع الدمج عند أي فشل.

**الحالة:** توجد حزم Windows مبنية باختبارات CI لكل من x86 وx64، لكن مطابقة جميع وظائف حضرموت والتحقق الميداني من MikroTik لم يثبتا بالكامل بعد. راجع ملفات المراجعة المرحلية ضمن `docs/`.

## استقلال مستودع NajimCardNew

هذه نسخة عمل مستقلة من `salehbinamrat/NajimCard`، نُسخت ملفاتها الأصلية من SHA:
`737f6d4f1104f7371231161582e6b4e55cc0300a` دون أي كتابة إلى المستودع الأصلي.

- المستودع الأصلي للقراءة فقط، وأي تغيير فيه يتطلب توجيها صريحا منفصلا.
- معرف تثبيت Inno Setup ومجلد تثبيت NajimCardNew منفصلان عن NajmCard الأصلي.
- قاعدة SQLite ومجلد النسخ وملفات اتصالات MikroTik وبيانات الترخيص المحلية تستعمل مجلد `%LOCALAPPDATA%\\NajmCardNew`؛ ولا تُستورد بيانات التطبيق الأصلي تلقائيا.
- تُسمى حزم x86/x64 Portable/Installer باسم `NajimCardNew`. ما زال ملف التشغيل داخلها `NajmCard.exe` للحفاظ على توافق بنية التطبيق الحالية؛ لكنه يوضع في مجلد تثبيت منفصل.
- خدمة التحقق من الترخيص عبر الإنترنت لم تُفصل بعد. فصل ملفات الترخيص المحلية لا يعني إنشاء خدمة تراخيص مستقلة.
- لا يُعد دعم RouterOS v7 أو حل مشكلة اتصال كروت User Manager بالإنترنت مكتملين بمجرد نسخ المصدر؛ تُعالج هذه المهام في مراحل مستقلة مع الاختبارات.

## تشغيل النسخة المحمولة واختصار سطح المكتب

- نزّل حزمة `Portable.zip` المطابقة لمعمارية Windows لديك، واستخرج **كل محتوياتها** إلى مجلد ثابت؛ لا تفتح الملف المضغوط مباشرة.
- في جذر المجلد يوجد ملف واحد مرئي لتشغيل البرنامج `NajmCard.exe`، يحمل أيقونة نجم كارد. يتولى هذا الملف تشغيل التطبيق الكامل من مجلد `App`.
- مجلد `App` يحتوي ملفات .NET وSQLite وملفات الواجهة الضرورية؛ **لا تحذفه أو تنقل مكوناته منفردة** وإلا قد يتوقف البرنامج.
- لإنشاء اختصار: شغّل البرنامج من الملف الخارجي، ثم افتح «الإعدادات» واضغط «إنشاء اختصار على سطح المكتب». الضغط مرة أخرى يحدث نفس الاختصار ولا ينشئ اختصارا مكررا.
- عند نقل مجلد Portable إلى مكان مختلف، افتح البرنامج من موقعه الجديد وأعد إنشاء الاختصار، لتحديث المسار.
- في نسخة `Installer` يظهر خيار «إنشاء اختصار على سطح المكتب» اختياريا أثناء التثبيت. الاختصار يشير إلى الملف الخارجي نفسه، والتثبيت لا يفرض إنشاءه.
- بيانات المستخدم وملفات ترخيصه وقاعدة SQLite تبقى منفصلة تحت `%LOCALAPPDATA%\\NajmCardNew`، ولا تُحفظ بجوار ملفات البرنامج المحمول.

يتحقق مسار البناء من معمارية الملفين التنفيذيين، وسلامة بنية ZIP، وتشغيل فحص المجلد المدمج في الملف الخارجي، ووجود حزمتي Portable وInstaller لكل معمارية قبل اعتماد الإصدار. هذه الفحوص لا تغني عن تجربة تشغيل ميدانية على جهاز العميل والطابعة والراوتر.
