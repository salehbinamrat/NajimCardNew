# نجم كارد | NajmCard

تطبيق Windows مستقل لإدارة وطباعة كروت MikroTik، يُعاد تطويره من الصفر بلغة **C# / .NET 10 / WPF**.

## نطاق المطابقة المعتمد

المطلوب **تطابق جميع صفحات حضرموت ووظائفه وسلوك العمليات والتقارير والطباعة وإدارة MikroTik**؛ وليس مجرد واجهة مشابهة.

- هوية بصرية: العنابي المذهب مع أيقونات متجهية متعددة الألوان، إطارات هندسية، ورسوم بيانية لبيانات الشبكة الفعلية.
- فصل كامل عن `salehbinzain83-star/Hadramout-cards`، وعن قاعدة بياناته وملفات تشغيله وتراخيصه.
- لا تُستعمل ملفات Python أو أطر تشغيله داخل التطبيق النهائي.
- جميع التغييرات تمر عبر PR واختبارات أولاً؛ يتزامن Windows Core وWindows Release على نفس SHA. يُبنى x86/x64 Portable وInstaller بعد الاختبارات ويُمنع الدمج عند أي فشل.

**الحالة:** مستودع جديد قيد التطوير. لم يتم إثبات مطابقة وظائف حضرموت كاملة، ولم تُعتمد حزم Windows بعد. راجع فرع التطوير `feature/port-hadramout-functional-parity` للاختبارات والمصفوفة المرحلية.

## استقلال مستودع NajimCardNew

هذه نسخة عمل مستقلة من `salehbinamrat/NajimCard`، نُسخت ملفاتها الأصلية من SHA:
`737f6d4f1104f7371231161582e6b4e55cc0300a` دون أي كتابة إلى المستودع الأصلي.

- المستودع الأصلي للقراءة فقط، وأي تغيير فيه يتطلب توجيها صريحا منفصلا.
- معرف تثبيت Inno Setup ومجلد تثبيت NajimCardNew منفصلان عن NajmCard الأصلي.
- قاعدة SQLite ومجلد النسخ وملفات اتصالات MikroTik وبيانات الترخيص المحلية تستعمل مجلد `%LOCALAPPDATA%\\NajmCardNew`؛ ولا تُستورد بيانات التطبيق الأصلي تلقائيا.
- تُسمى حزم x86/x64 Portable/Installer باسم `NajimCardNew`. ما زال ملف التشغيل داخلها `NajmCard.exe` للحفاظ على توافق بنية التطبيق الحالية؛ لكنه يوضع في مجلد تثبيت منفصل.
- خدمة التحقق من الترخيص عبر الإنترنت لم تُفصل بعد. فصل ملفات الترخيص المحلية لا يعني إنشاء خدمة تراخيص مستقلة.
- لا يُعد دعم RouterOS v7 أو حل مشكلة اتصال كروت User Manager بالإنترنت مكتملين بمجرد نسخ المصدر؛ تُعالج هذه المهام في مراحل مستقلة مع الاختبارات.
