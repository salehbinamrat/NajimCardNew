# تريم كارد — 1.0.0-rc.1

هذا مرشح للاختبار، وليس إصدار 1.0.0 نهائياً. يتطلب اعتماداً ميدانياً مستقلاً قبل الترقية إلى إصدار مستقر.

- سلامة User Manager v6: ربط الباقات والقيود بالمعرف والمالك، والاحتفاظ بالقيم المجهولة، والتحقق المستقل قبل الحذف.
- حماية الدفعات بهوية الراوتر وسجل محاولات دائم؛ مطابقة الحالات المعلقة قبل استكمال ما ثبت غيابه.
- قراءات RouterOS محددة ومخبأة بوضوح، مع إبطال دقيق للذاكرة المؤقتة وحماية النقل من الانقطاع والبيانات التالفة.
- توليد أرقام في المساحات شبه الممتلئة، وفحص التعارضات قبل الحفظ، وقياس مراحل الإرسال والتحقق والحفظ والطباعة.
- تقارير تراعي تداخل الجلسات والفترات دون اختراع توزيع يومي، وتصدير يلتزم بالمرشحات دون بتر صامت عند 10,000 سجل.
- حماية CSV من صيغ Excel، وتصدير بيانات الإرسال الفعلية، ونسخ كاملة بالصور مع استعادة معزولة ونسخة رجوع.
- استكمال الأزرق الكهربائي والفضي في قوائم الإنشاء والطباعة والتقويم والمحرر والحوارات، والتفاف التلميحات الطويلة.
- إبقاء مقاس 1260×730 عندما يتسع له سطح المكتب، واحتواء التصميم تناسبياً عندما يقل مجال العمل بسبب الدقة أو تكبير Windows.
- إصلاح إلغاء قراءة FTP العالقة أثناء استقبال قائمة الملفات؛ لا إعادة رفع تلقائية بعد نتيجة غير مؤكدة.
- اختبارات Windows تشترط معمارية العملية الفعلية، وتشمل تشغيل Portable والتثبيت والتحديث والإزالة مع فحص بقاء البيانات.

يبقى ترخيص Windows مرتبطاً بحساب المستخدم ومفاتيح DPAPI. النسخ لا تحول كلمات المرور المشفرة إلى كلمات مرور قابلة للنقل إلى حساب مختلف. لا تغيير لمستودع حضرموت أو لاستحقاقات الترخيص المشترك.

يضم ملف توزيع كل معمارية Portable وInstaller وملف SHA256SUMS. تفصل تقارير Actions بين نتائج المحاكاة، وعرض WPF، وتشغيل الحزم، والاختبارات الميدانية التي لم تنفذ بعد.
