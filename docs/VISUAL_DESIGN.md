# نجم كارد — مواصفات التصميم المعتمدة

## الهوية البصرية

- خلفيات عنابية متعددة الطبقات: `#160810`, `#270C19`, `#361021`, `#621B37`.
- تفاصيل مذهّبة هادئة: `#DCB86E`, `#FFE3A2`; العناوين والعناصر الرئيسية من دون إفراط في الوهج.
- ألوان أيقونات وظيفية متفاوتة لكن منسجمة: ذهب، أخضر زمردي، أزرق، تركواز، أرجواني، وردي.
- أيقونات نجم كارد مستقلة، أصلية، متجهية وقابلة للقياس عبر WPF `PathGeometry`؛ لا تعتمد على صور مكسورة أو خطوط رموز خارجية.
- الاتجاه عربي RTL، والأرقام وحقول IP وكلمات المرور بالإنجليزية LTR.

## الرئيسية

- 4 بطاقات هندسية: إجمالي الكروت، المتصلون، الكروت غير المعطلة، المنتهية بالاستهلاك (Transfer Limit فقط).
- مخطط حلقي أصلي يعتمد على البيانات الفعلية: متاحة، منتهية بالاستهلاك، معطلة غير منتهية. كل كرت يظهر في فئة واحدة فقط.
- مؤشرات المعالج والذاكرة من `/system/resource/print` مع حدود 0–100%.
- رسم أعمدة لأكثر أربع باقات استخداماً، متصل ببيانات Hotspot الحقيقية وليس عينات وهمية.
- بطاقة الراوتر وتفاصيل إصداره، وأزرار انتقال فعالة إلى إنشاء الكروت وإدارتها والتقارير.
- لا توجد عناصر تجريبية مضللة أو أرقام افتراضية على أنها حقيقية.

## صفحة إلى أخرى

- الشريط الجانبي يميز الصفحة المختارة، وكل صفحة لها لون أيقونة مميز.
- تصميم حقول وأزرار وجداول متسق عبر واجهة واحدة، دون تكرار قائمة الوظائف.
- عمليات الراوتر المؤثرة (إرسال/تعطيل/حذف) تتطلب تأكيداً صريحاً.
- ميزات حضرموت التي لم تنقل بعد موضحة في `PORTING_MATRIX.md`، ولا تُعرض أزرار وهمية.

## حدود التنفيذ الحالية

تم تصميم وتنفيذ واجهة أولية قابلة للبناء مصدرّياً. لم تؤكد نتائج بناء Windows بعد لعدم وجود مستودع NajmCard مستقل صالح لتشغيل GitHub Actions. لا تعتبر إصداراً إنتاجياً حتى تنجح اختبارات Windows الفعلية والمراجعة المرئية.
