# نجم كارد — Najm Card

مشروع **مستقل تماماً** عن حضرموت لإدارة وطباعة كروت MikroTik، مكتوب من الصفر بـ **C# و.NET 10 وWPF**؛ جميع شاشاته RTL، بهوية **العنابي المذهّب** وأيقونات متجهية متناسقة.

## المرحلة الحالية — إصدار تأسيسي 0.1.0

- شاشة دخول RouterOS API v6 مع TLS اختيارية بشهادة موثوقة.
- لوحة رئيسية ببطاقات هندسية مع مخطط حلقي، أعمدة الباقات، مؤشرات CPU والذاكرة والأرقام الحية للمتصلين والكروت.
- أيقونات متجهية أصلية من ملف `Themes/VectorIcons.xaml` لكل عنصر في الشريط الجانبي؛ لون مختلف لكل وظيفة.
- إنشاء دفعات كروت بأرقام عشوائية فريدة، حفظها في SQLite محلياً مع حماية كلمات المرور بـ Windows DPAPI، وإرسالها للراوتر بعد التأكيد.
- عرض Hotspot وباقاته وجلساته وسيرفراته، تفعيل/تعطيل/حذف كرت بعد التأكيد.
- طباعة أساسية، وتصدير CSV، ونسخ احتياطي محلي.

**مهم:** هذا تأسيس جديد، **وليس بعد نسخة مطابقة لكل وظائف حضرموت**. محرر طباعة القوالب المتقدم، Excel الكامل، User Manager v6، وأدوات VPN/Winbox لم تكتمل. انظر `docs/PORTING_MATRIX.md`.

## عدم المساس بحضرموت

- المستودع المستهدف الجديد: `salehbinzain83-star/NajmCard`، منفصل تماماً عن `salehbinzain83-star/Hadramout-cards`.
- لا توجد ملفات Python أو مفاتيح تراخيص/واجهات Supabase خاصة بحضرموت داخل هذا المشروع.
- جميع بيانات نجم كارد المحلية تحت `%LOCALAPPDATA%\NajmCard\Data`، دون الوصول إلى بيانات حضرموت.
- جميع العمليات على الراوتر تُجرى عبر الاتصال الصريح بالمستخدم، ولا تحدث لمجرد فتح لوحة التحكم.

## التطوير والبناء

يتطلب **Windows 10 أو أحدث** و.NET SDK 10.0 وInno Setup 6. لا يحتاج إلى Python لتشغيل البرنامج.

```powershell
dotnet restore NajmCard.slnx
dotnet build NajmCard.slnx --configuration Release
dotnet test tests/NajmCard.Core.Tests/NajmCard.Core.Tests.csproj --configuration Release
```

يتضمن `.github/workflows/windows-ci.yml`:
1. Windows Core وWindows Release (x86 وx64) يعملان بالتوازي على SHA واحد.
2. الاختبارات تنفذ قبل إنشاء الحزم.
3. بعد نجاح جميع الاختبارات تُبنى الحزم الأربع: x86/x64 Portable وInstaller، وتتحقق معمارية PE والبصمات SHA-256.
4. لا يدمج أي طلب PR إلى `main` إذا فشل اختبار أو بناء.

**التحقق:** اجتازت ملفات XAML فحص XML والفحوص البنيوية المحلية الأربع. لم يجرِ بعد تجميع فعلي بـ .NET/WPF على Windows، ولذلك لا توجد حزم EXE تم اعتمادها. انظر `docs/VISUAL_DESIGN.md`.
