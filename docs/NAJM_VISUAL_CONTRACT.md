# Visual design requirements for NajmCard
- Burgundy base: deep garnet and oxblood gradients, layered with restrained gold highlights.
- Every page, toolbar, dialog and context menu must follow a consistent RTL theme.
- Multiple coherent colored SVG/WPF vector icons; gold should not be the only accent. Distinct categories use teal, sapphire, violet, amber and coral.
- Dashboard: responsive geometrical frames and varied-size tiles; circular distribution chart, vertical profile bars, actual CPU/RAM gauges, online users and card lifecycle metrics. Never show invented or demo figures in production.
- Pressing each card leads to its owning function. Navigation has no duplicate entries and clearly identifies the active selection.
- Graphics must not obscure tabular data or core operations, and should avoid horizontal scroll at common desktop widths.
- Printing/designer remains fully usable with mouse, keyboard and scaling.
- Preserve the Hadramout content/behavior, but create entirely new artwork and implementation for NajmCard.
